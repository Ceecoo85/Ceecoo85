# Ceecoo85

## LinkedIn skills

Vendored from [sergebulaev/linkedin-skills](https://github.com/sergebulaev/linkedin-skills)
(commit `14d332b`, MIT — see `LICENSE-linkedin-skills`).

- `skills/` — the 12 skills (post writer, comment drafter, reply handler, humanizer,
  profile optimizer, content planner, hook extractor, repurposer, interviewer,
  thread monitor, engager analytics, employee advocacy)
- `references/` — shared reference files the skills link to via `../../references/`
- `lib/` — optional Python helpers (Apify for reading, Publora for publishing);
  `pip install -r requirements.txt` and set API keys in the environment to use them
- `.claude/skills/` — symlinks so Claude Code picks the skills up automatically
  when this repo is the working directory

Nothing is published without your explicit approval.
